# مِسبار | MISBAR

Bilingual hackathon discovery platform for all Arab countries.

## MVP
- Arabic/English interface toggle
- Search by name, field, or description
- Filter across 22 Arab countries
- Responsive static frontend
- GitHub Pages deployment workflow

The current cards are demo data and must be replaced with verified event sources before public launch.

## Cloud roadmap
1. Publish the static MVP with GitHub Pages.
2. Replace demo data with Supabase.
3. Add an admin review workflow.
4. Add optional AI summaries after verifying free-tier limits.
